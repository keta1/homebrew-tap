# Keta1 Tap

## How do I install these formulae?

`brew install keta1/homebrew-tap/<formula>`

Or `brew tap keta1/homebrew-tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "keta1/homebrew-tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
